An AI terminal that lives on your iPhone.

Monico runs its directive engine, forensic scanner, and health guard entirely on-device. No API keys, no cloud calls, no accounts — open the app and it works, even offline. Every command is real: processes, disk, and system stats are read from the device itself.

What it does

Three tabs, one local engine. Everything below runs against this device's real APIs.

⌁

Terminal

Command input with history and tap-to-run chips, ten real on-device commands (help, health, sysinfo, uptime, date, echo, cpu, disk, ps), and an honest unknown-command error. Input is length-capped and output is HTML-escaped.

◉

Forensics

Real on-device scan: live process table ranked by CPU, network connection count, and disk usage — powered by psutil, nothing leaves the phone.

⚙

System & Health Guard

Live CPU/memory gauges, platform and hardware detail, and the iOS health guard that flags THROTTLING above 25% CPU to protect thermals.

🔒

Private by construction

The local server binds to 127.0.0.1 only, the UI has zero CDN dependencies, and there is no key, token, or account anywhere in the build.

Build it

Desktop preview runs anywhere Python does. The native iOS build needs macOS + Xcode (GitHub Actions builds the IPA on every push).

01 — PREVIEW

Run the web UI

Same UI the iOS WebView renders, served locally.

pip install -r requirements.txt
python app.py   # → http://127.0.0.1:5000
02 — TEST

Run the test suite

API routes, UI assets, and health guard — all real.

pip install pytest
pytest tests/ -q
03 — SHIP

Build the IPA

macOS + Xcode, or push and let CI build it — every push runs the iOS Release Build workflow and uploads the Monico-iOS-IPA artifact.

pip install briefcase
briefcase create ios
briefcase build ios
